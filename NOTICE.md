# Third-party notices

Hexie uses open-source software and fonts. This file lists external components
and their licenses.

## npm dependencies

| Package | License | Role |
|---------|---------|------|
| React, React DOM | MIT | UI framework |
| Vite | MIT | Build tool |
| Tailwind CSS | MIT | Styling |
| Lucide React | ISC | Icons |
| Pyodide | MPL-2.0 | In-browser Python (loaded from CDN at runtime) |
| ESLint and plugins | MIT | Linting |
| @fontsource/space-grotesk | OFL-1.1 | UI font |
| @fontsource/jetbrains-mono | OFL-1.1 | Code font |

Full license texts are in `node_modules/<package>/LICENSE` after `npm install`.
